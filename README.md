# Asset Management System

## Project Goal

The goal of the Asset Management System is to provide a centralized way to
record, organize, and monitor an organization's physical assets. The system is
intended to help administrators maintain an inventory, associate assets with
categories and employees, and review key asset information such as
manufacturer, serial number, and purchase date. By keeping this information in
one place, the project aims to improve inventory visibility, accountability,
and the efficiency of day-to-day asset administration.

The project uses HTML, CSS, and JavaScript for its web interface, Node.js for
the application backend, and PostgreSQL for persistent data storage. Its
database schema includes records for administrators, categories, employees,
and assets, with relationships linking assets to their category and assigned
employee.

The current interface includes login and dashboard pages. Dashboard totals
are sample content, and backend functionality is not yet implemented; these
pages and the database schema represent the foundation for the intended
system.
